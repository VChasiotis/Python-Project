# Python Project  
*A two-part Python application combining data processing and a custom AI model with GUI interfaces*

## 📌 Overview  
This repository contains two independent Python applications:

- **Part A — World Cup 2022 Top Scorers Manager**  
  A menu-driven program that loads, displays, sorts, searches, and exports player scoring data. Includes robust error handling and a GUI version.

- **Part B — Neural Network Training Application**  
  A Python program implementing a **from-scratch neural network (back-propagation)**. Allows users to load training vectors, train the network, and view results through a GUI.

Both parts demonstrate strong Python fundamentals, clean modular design, and practical GUI implementations.

---

## 🚀 Features  

### **Part A — Football Top Scorers Application**
- Menu interface with 7 actions:
  - Load scorer data from file  
  - Display all players  
  - Sort by goals, name, or team  
  - Search / filter players  
  - Update statistics  
  - Export results  
  - Launch GUI version  
- Error handling for invalid input and file issues  
- Functions organized for clarity and reuse  
- GUI built using Python’s standard toolkit (e.g., Tkinter)

---

### **Part B — Neural Network Training Application**
- Menu-based system with 5 core options:
  - Load training vectors from file  
  - Initialize and train a neural network  
  - Display training progress (epochs, loss, accuracy)  
  - View final results and evaluation  
  - Launch GUI version  
- Full custom implementation:
  - Forward propagation  
  - Back-propagation  
  - Weight updates and accuracy tracking  
- GUI for user-friendly interaction and visualization
